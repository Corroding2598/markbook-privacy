鸿签（MarkBook）隐私政策

生效日期：2026 年 11 月 22 日 · 版本 2.2

本政策适用于「鸿签」（应用包名 cn.hongqian.markbook）HarmonyOS 客户端与配套浏览器扩展。本应用由范祺玥独立开发并运营。

我们不需要你注册账号，也不设服务器保存你的数据。本政策的目的是清楚说明应用会接触哪些信息、为什么接触、这些信息去了哪里。

一、我们不会收集的信息

本应用不收集、不上传、不共享以下信息：

  • 设备标识符（IMEI、OAID、IDFA、设备序列号等）
  • 手机号、邮箱、身份证件等身份信息
  • 精确或粗略地理位置
  • 通讯录、短信、通话记录
  • 相册、麦克风、摄像头、剪贴板
  • 应用列表、已安装应用信息
  • 使用行为、点击埋点、崩溃堆栈

本应用不接入任何第三方统计、广告、推送、崩溃上报 SDK。

二、本机保存的信息

以下信息仅保存在你的设备本地，存储于应用沙箱或浏览器扩展本地存储中：

信息用途保存期限
书签记录（标题、网址、所属文件夹、排序、修改时间、本机随机设备标识）实现书签管理、排序与多端合并直至你在应用内删除或卸载应用
文件夹结构与排序实现分类浏览同上
删除传播记录让删除同步到其他设备；不在界面展示，不进入 JSON 备份长期保留用于删除传播，直至卸载应用
历史快照（自动 / 手动 / 保护）用于回滚到之前的书签库状态；自动按保留天数滚动，手动快照只有你主动删除自动按设置天数，手动/保护长期保留，直至你删除或卸载应用
显示设置（主题模式等）记住你的显示偏好直至卸载应用
同步设置（WebDAV 地址、账号、应用密码）连接你指定的同步服务器直至你在设置中清空或卸载应用

同步设置中的账号与应用密码属于敏感信息，仅保存在本机应用沙箱或扩展本地存储中，未加密存储，也不进入同步快照、导出文件或应用日志。请使用专门为该用途生成的「应用密码」，不要使用第三方服务的登录密码。

应用提供「回收站」。删除书签或文件夹时会写入一条删除记录，该记录保存在本地并随你的同步快照传播到你的其他设备，你可以在「整理与维护 → 回收站」把它恢复到原位置。删除记录不在主列表展示，也不进入导出的 JSON 或 HTML 备份。删除后另有 4.5 秒的界面内撤回提示。

三、从其他应用接收的内容

应用可在系统分享面板中接收其他应用发来的网页链接与纯文本。收到内容后，应用会打开「新建书签」面板并预填标题与网址，只有你点击保存后才写入本地。

  • 接收的内容仅在内存中用于预填表单，未保存时不落盘
  • 应用不记录该内容来自哪个应用，也不上传
  • 接收行为由你主动分享触发，应用不会在后台读取其他应用的数据

四、系统权限与网络请求

应用仅申请一项系统权限：网络访问（ohos.permission.INTERNET），用于 WebDAV 同步、抓取网站图标、失效链接检测，以及你主动打开的书签链接。应用不申请存储、剪贴板、相机、麦克风、位置、通讯录、通知等任何其他权限，安装后不会出现任何运行时授权弹窗。扩展仅申请 bookmarks 与 storage 权限，并在你点击测试连接或同步时申请对应 WebDAV 站点的访问权限。

网络请求只发生在以下情形：

1. WebDAV 同步（由你配置并触发）

只有你在设置中自行填写 WebDAV 地址、账号与应用密码（即使用你自己的 WebDAV 账户登录）后，应用才会连接你指定的服务器。地址强制 HTTPS，http:// 地址拒绝保存与同步。凭据只保存在本机，不进入同步快照、导出文件或日志。

  • 传输内容：书签与文件夹快照（标题、网址、层级、排序、修改时间、本机随机设备标识、删除传播记录），以及历史快照（合并后的书签库状态，含备注、标签、忽略规则与收件箱状态）
  • 数据接收方：你填写的 WebDAV 服务提供方（如坚果云、Nextcloud、群晖或自建服务），其处理受该服务方隐私政策约束
  • 应用不设默认服务器，不将数据发送到开发者或任何第三方地址
  • 「打开时同步」默认关闭；开启后手机仅在冷启动尝试一次，扩展在点击工具栏插件按钮打开弹窗时尝试。不实现定时同步、书签事件同步或后台自动重试

2. 打开书签链接

当你点击书签时，应用通过系统能力把网址交给已安装的浏览器打开。此后页面访问行为由该浏览器及对应网站负责。

3. 网站图标抓取（自动发生）

为在列表中显示站点图标，应用会向你收藏的站点请求其公开的图标文件（通常位于站点根目录）。若根目录未取到，应用会再请求该站点的首页 HTML，读取页面中声明的图标地址后再取图标。

  • 触发时机：列表需要显示图标时自动发起，无需你任何操作
  • 不携带内容：不发送书签标题、账号、备注、标签或任何本地数据，也不带应用标识
  • 对外可见的信息：仅你的网络出口 IP 与该站点的一次常规访问关系
  • 图标只缓存在本机，不上传；未配置同步、未点击书签时，这是应用唯一的自动网络行为

4. 失效链接检测（由你触发）

仅当你主动点击「开始检测」时执行：应用会用 HEAD 请求逐个访问书签地址以判断是否可达，不下载页面正文，不自动删除或修改任何条目。建议在 Wi-Fi 环境下使用。

五、信息的对外提供

除上述你主动配置的 WebDAV 同步，以及为显示图标而自动发起的目标站点请求外，我们不会向任何第三方提供、转让或公开披露你的信息。应用不含第三方 SDK。

六、你的权利

  • 查看与更正：所有书签数据均可在应用内直接查看和修改
  • 删除：可删除单条书签或整个文件夹；卸载应用将删除本机全部应用数据
  • 撤回同意：卸载应用即视为撤回同意；也可在系统设置中清除本应用数据
  • 拒绝同步：不填写 WebDAV 设置即不会发生任何同步，应用完全以离线方式使用。请注意，为在列表显示网站图标，应用仍会向你收藏的站点请求其公开图标文件（必要时包含该站点首页）；若需彻底禁止联网，可在系统设置中限制本应用的网络权限或清除应用数据

由于我们不持有你的任何数据，我们无法、也无需提供远程数据导出或删除服务。

七、未成年人保护

本应用为通用书签工具，不面向未成年人单独设计，不收集年龄信息，不含社交、付费或内容推荐功能。未成年人使用应在监护人指导下进行。
